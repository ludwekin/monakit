# ExpressLRS 2.4G 接收机复刻与调试过程记录

从电压分压采样、RFIO 匹配电路、VNA 调匹配，到 AT2401C / Skyworks 前端芯片对比，再到 ESP32-C3-WROOM-02 刷 BAYCKRC 固件，全程实战笔记。目标是复刻/优化一款稳定、低延迟、远距离的 ELRS Nano RX。

## 第一步：电池电压测量 - 10:1 分压电路

ESP32-C3 的 GPIO ADC 最高耐压 **3.3V**（内部参考电压通常 ~1.1V，中值配置下满量程约 0–3.3V，视衰减档而定）。

要测量最高 36.3V 的电池电压（例如 8S LiPo ≈ 33.6V 满电），采用 **10:1 分压**：

- 上电阻 R1、下电阻 R2 比例为 9:1（例如 R1=90kΩ, R2=10kΩ，总阻 100kΩ）。
- 分压公式：Vout = Vin × (R2 / (R1 + R2))
- 当 Vin=36.3V 时，Vout ≈ 3.63V（略超 3.3V，但实际满电留余量，配合软件限幅/校准安全）。
- 建议用 1% 精度电阻 + 并联 0.1μF 去耦电容到地，减小噪声。
- ADC 采样时选高阻抗模式，避免漏电影响（ESP32-C3 漏电流 max 50nA，高阻分压时压降可忽略）。

## 第二步：SX1281 RFIO 引脚 - 参考匹配电路

SX1281（Semtech 2.4GHz LoRa/FLRC 收发芯片）RFIO 引脚需接 **参考匹配电路**（参考 Semtech datasheet 第 15.1 节 Reference Design）。

典型结构：**L/C π 型滤波 + 匹配电感**。

常见 π 型网络（从芯片到天线方向）：

- SX1281 RFIO → **C_shunt1**（并联到地，靠近芯片，吸收芯片端寄生）
- → **L_series**（串联电感，做阻抗变换）
- → **C_shunt2**（并联到地，靠近天线，微调天线端容性分量）
- → 天线 或 IPEX 座

**RF 走线必须 50Ω 阻抗控制**：用 Saturn PCB Toolkit 或 Polar Si9000 计算线宽/间距（参考板材 Er、厚度、铜厚）。

## 第三步：天线匹配调试 - 用 VNA 调到 S11 < -10dB

**S11**（反射系数）表示从芯片发出的 RF 信号有多少被反射回来（越小越好，-10dB 意味着 90% 功率传输，-20dB 更好，99%）。

调试目标：**S11 < -10dB**（理想 -15dB ~ -20dB），主要通过**微调匹配网络里的电容（C）和电感（L）**实现。

- 电阻 R 几乎不用（会引入损耗，降低效率和链路预算）。
- 步骤：
  1. 先焊参考值（datasheet 推荐 BOM）。
  2. 用矢量网络分析仪（VNA）测 S11（Smith 图上看点尽量靠近中心）。
  3. 根据 Smith 图偏移，增/减 C_shunt1/2 或 L_series（常用 0402/0201 贴片，0.1pF/0.5nH 步进更换）。
  4. 反复迭代，直到中心频率 2450MHz 处 S11 最低。

## 第四步：2.4GHz RF 前端芯片对比

### AT2401C
国产中科微等厂商的 2.4GHz RF 前端单芯片（RF Front-End IC），常用于替换/兼容 RFX2401C。

- 典型应用：nRF24L01+PA+LNA 模块（淘宝常见 2.4G 模块）。
- 集成 PA、LNA、T/R 开关、匹配等，适合 Zigbee/ISM 低功耗场景。

### Skyworks 系列对比

- **SKY65404-31**：专用超低噪声放大器（LNA），仅接收端，频段 4.9–5.9GHz（5GHz Wi-Fi/专用），不含 PA/开关。
- **SKY66408-11**：完整 RF 前端模块（FEM），2.4GHz（2400–2500MHz），集成 PA、LNA、T/R 开关、滤波，甚至 I²C 功率调节。适合 Zigbee/Bluetooth/Thread/IoT，高集成度，链路预算更好。

AT2401C 更偏向低成本替换，SKY66408-11 功能更全、性能更稳。

## 第五步：ESP32-C3 刷固件实战（BAYCKRC 2.4G NANO RX）

目标模块：**ESP32-C3-WROOM-02-N4**（内置 USB，无需 CH340/CP2102，刷机方便，还可做 USB HID 遥控器）。

刷固件注意事项：

- **BOOT 按钮**：按住不放（进入下载模式），连接 USB。
- **TX/RX 引脚**：助焊剂残留或短路会导致刷写失败，先用酒精+刷子清洁。
- **推荐方式**：用 ExpressLRS 在线刷写器 https://expresslrs.github.io/web-flasher/（3.5.1 及以上版本直接支持）。
- 固件选择：**BAYCKRC 2.4G NANO RX**（或对应目标，确保与 TX 匹配）。
- 步骤：
  1. 进入 web-flasher，选择设备 → ESP32-C3。
  2. 选固件 target（BAYCKRC 或兼容 Nano RX）。
  3. 按住 BOOT 连接 USB → 自动识别 → 刷写。
  4. 成功后松开按钮，重启。

新版 ELRS 直接 WiFi 刷（需先刷 2.5.2 过渡版再到 3.x，避免空间不足）。

## 总结：ELRS 2.4G Nano RX 优化建议

1. **电压采样**：10:1 分压 + 软件校准，确保 ADC 安全读 8S 电压。
2. **天线匹配**：VNA + π 型 L-C 网络，S11 目标 -15dB 以上。
3. **RF 前端**：预算足选 SKY66408-11（全功能），成本控选 AT2401C。
4. **固件**：在线刷 BAYCKRC 目标，BOOT 按住 + 清洁引脚是关键。

做好这些，您的 ELRS 接收机链路预算、距离、抗干扰都能大幅提升。实战多测 RSSI/SNR，调好再飞，安全第一！
