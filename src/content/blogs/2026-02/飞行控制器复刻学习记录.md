# STM32 DFU 与 Bootloader 实战笔记：Zadig、USB DFU、SWD、飞控移植

STM32 的 DFU（Device Firmware Upgrade）是开发/量产最常用的 USB 升级方式。本文从 Zadig 驱动安装聊起，一路讲到系统 Bootloader（ROM 固化）、BOOT0 配置、在线跳转、USB 接线、系列支持差异，再到 Betaflight 固件代码移植 CubeIDE（F405 主控 + ICM42607 IMU + BMP280 气压计）的实战流程。适合复刻飞控或自研智能硬件。

## 第一步：Zadig —— Windows 下 STM32 DFU 驱动安装神器

Zadig 是一款免费的 USB 设备驱动安装工具（https://zadig.akeo.ie/），专门用来替换 Windows 默认驱动为 **WinUSB**（或 libusbK），让 STM32 Bootloader 在 DFU 模式下被电脑识别。

常见场景（飞控/Betaflight/iNav/PX4 等）：
- 按住 BOOT 按钮 + 插 USB → 进入 DFU 模式。
- 设备管理器出现 “STM32 BOOTLOADER” 或未知设备。
- 运行 Zadig（以管理员身份）：
  1. Options → List All Devices。
  2. 选 “STM32 BOOTLOADER” （VID:PID 通常 0483:DF11）。
  3. 驱动选 WinUSB → Install Driver / Replace Driver。
- 成功后，STM32CubeProgrammer / dfu-util / Betaflight Configurator 就能通过 USB DFU 烧录固件。

**小贴士**：如果没出现设备，先确认 BOOT0=1（高电平）。ImpulseRC Driver Fixer 是简化版替代工具（一键装驱动）。

## 第二步：STM32 系统 Bootloader —— 出厂固化在 ROM（System Memory）

绝大多数 STM32 芯片在出厂时，就有一段 **系统 Bootloader** 固化在芯片内部的 **ROM（System Memory）** 里（Mask ROM，掩膜固化，不能擦除、不能修改）。

- 位置：通常在 0x1FFF0000 ~ 0x1FFFxxxx（具体地址见 AN2606）。
- 功能基础：支持 UART、USB DFU、CAN、I2C、SPI 等（视系列而定）。
- 进入方式：
  - 硬件：BOOT0 = 1（高电平） + 复位 → 直接跳进 ROM Bootloader。
  - 软件：在用户程序运行时，发送“升级命令” → 关闭中断、设置栈指针、跳转到 System Memory 地址 → 实现在线升级（无需按 BOOT 按钮）。

**ROM Bootloader 能删吗？** 不能。除非芯片物理损坏，否则永久存在。

**PX4 / Betaflight 烧录前**：先用 STM32CubeProgrammer 烧一个自定义 Bootloader 到 Flash（保护区），再烧应用固件。

## 第三步：BOOT0 引脚配置与启动序列

BOOT0 不需要在程序里配置，它是**硬件引脚**。

- 默认：BOOT0 通过下拉电阻接 GND（=0）。
- 进入 Bootloader：BOOT0 接高电平（3.3V） + 复位（上电/按 RESET/NRST）。
- 芯片上电后执行固定 **Reset Sequence**：
  1. 读取 BOOT0 值。
  2. 根据 BOOT0/BOOT1（部分系列有）决定映射到 0x00000000 的区域：
     - BOOT0=0 → Flash（用户程序）。
     - BOOT0=1 → System Memory（ROM Bootloader）。
  3. 内部地址映射器（Alias Region）把对应内存别名到 0x00000000。
