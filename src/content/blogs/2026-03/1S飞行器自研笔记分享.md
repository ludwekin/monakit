主控选型：F411 / F435 / G473 都行STM32F411：经典低成本，100MHz，512KB Flash，128KB RAM。适合入门 1S Whoop，Betaflight 现成 target（如 CRAZYBEEF4FR、HAPPYMODEL 等）。缺点：IO 少、Flash 有限。
STM32F435：更高主频（168MHz+）、更多外设、更好浮点性能。适合加 OSD、黑匣子、双 IMU 或 ELRS 集成。
STM32G473：最新一代，170MHz、超低功耗、高精度 ADC、更多定时器。续航更长，Betaflight 推荐替代 F411 的首选（AT32F435 也是热门平替）。

三者引脚兼容度高，预算紧选 F411，追求性能选 F435/G473。Betaflight 通道映射：遥控器通道 → PWM 输出脚在 Betaflight CLI 里，一行就能映射：# 先释放原资源（如果有冲突）
resource PWM 1 NONE

# 映射 PWM1 到 PA8（常见 TIM1_CH1）
resource PWM 1 A08

# AUX1（通道 5）范围 900–2100 映射到 PWM1
aux 0 0 5 900 2100 0 0

常用引脚：PA8、PB6、PB7、PB8、PB9。作用：驱动舵机、LED、VTX 功率切换等。保存后重启生效。串口通讯基础：什么时候开始读、什么时候结束？普通 UART 硬件定义了一帧开始/结束：典型格式 8N1：1 起始位（0） + 8 数据位 + 1 停止位（1）。

起始位永远 0（下降沿触发）。
停止位必须 1（下一帧需 1→0 下降沿同步）。

RS232 是老标准（±12V），现代 STM32 用 TTL（0/3.3V）。工业协议示例：MAVLink 结构：
[头 0xFD] [长度] [序列号] [系统ID] [组件ID] [消息ID] [数据] [校验]两个各自用锂电池供电的 STM32 板串口怎么接？必须共地！正确接法：
板A TX → 板B RX
板A RX ← 板A TX
板A GND ─ 板B GND不接 GND 会乱码/读不到，甚至烧芯片。一定要共地，干扰大幅降低。4S 电池 + 配电板给飞控 + 模块供电，串口怎么接？4S → 配电板 → 两路 5V/GND 分别给飞控和模块。两个 GND 是同一个地。只需接 TX/RX 即可通讯。
强烈推荐再接一根 GND：降低干扰、稳定电平。ESC 转速 / 电流回传原理与选购设计普通电调：电流：ACS712 / 霍尔 → 模拟电压 → ADC
转速：反电动势（BEMF），低速不准

高级电调（DShot Telemetry）：FOC + 速度环精确估算 RPM
Bidirectional DShot：单线回传（电机相线调制），支持 RPM/电流/电压/温度

1S Whoop 怎么买？淘宝搜 “1S DShot Telemetry ESC” / “1S AIO 电调” / “Bluejay 1S”
推荐：Hobbywing 1S、BetaFPV / Happymodel 1S AIO
选支持 Bluejay 或 AM32 的，能免费开启 Bidirectional DShot + RPM Filtering

自研电调要点：主控：STM32G4 / EFM8
驱动：低内阻 MOSFET + 栅极驱动
固件：Bluejay / AM32 开源
加 Telemetry：DMA 捕获 + UART
1S 专用：体积 <15×15mm

Betaflight 配置 RPM Filtering：启用 Bidirectional DShot
设置 Motor Poles（通常 7/14）
用 esc-configurator.com 在线刷 Bluejay
