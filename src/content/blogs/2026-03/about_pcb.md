# PCB设计常见问题快速整理

## 1. 焊盘基本构成
焊盘 = **铜皮** + **表面处理层**  
（常见表面处理：HASL有铅喷锡 / Lead-free HASL / ENIG化学镍金 / OSP有机保焊膜 / 沉银 / 沉锡等）

## 2. 四层板层压顺序怎么制定？（哪一层靠近顶层？）

**最推荐的经典顺序（从顶到底）：**

1. Layer 1 → Top（顶层信号）
2. Layer 2 → **GND**（完整地平面，**紧邻顶层**）
3. Layer 3 → POWER（电源平面，或分区电源）
4. Layer 4 → Bottom（底层信号）

**为什么内层第一层优先放GND而不是POWER？**

- 高速/高频/敏感信号大多走顶层，GND最近 → 回流路径最短，寄生电感最小
- GND把信号层和电源层隔开，减少电源噪声耦合到信号
- 铜量相对对称，板子不容易翘曲

**其他常见变体（根据需求调整）：**

- Top → POWER → GND → Bottom（电源噪声更关键的场景）
- 六层常见：Top → GND → Inner Signal → POWER → GND → Bottom

**交付建议：**
- 在软件里设置好Stackup（层厚、铜厚、介质材料）
- 出Gerber必须附**层叠图**（Stack-up Drawing）
- 图上明确标注：  
  “Layer 2: GND plane, adjacent to Top Layer”  
  或直接写明层序和每层用途
- 邮件或BOM/说明里再次强调层压顺序，避免工厂默认压反

## 3. 铺铜时的“放置/移除缝合孔”是什么意思？

**缝合孔（Stitching Via / Via Stitching）**  
就是在铺铜区域（尤其是大面积地铜）里定期打一些**过孔**，把不同层的地铜连接起来，形成“多点连接”。

软件里的选项通常叫：
- Place stitching vias / Add via stitching
- Remove stitching vias

**作用：**
- 降低不同层地平面之间的阻抗
- 提供更多回流路径，减小地弹（ground bounce）
- 改善EMI（高频时特别重要）
- 增强大铜皮的散热和机械连接强度

**常见设置：**
- 网格间距 5–15mm（视频率而定，高速板更密）
- Via尺寸一般用过孔工艺的最小规格（如0.3/0.6mm）

## 4. 两个金属化过孔部分重叠会发生什么？

**结论排序（从严重到轻微）：**

- **板子容易断裂**（最严重情况）  
  过孔重叠 → 局部区域树脂含量严重不足 → 层压时应力集中 → 板子容易在此处开裂、分层

- **工程上可行，但强烈不推荐**  
  大部分正规PCB厂都能压出来（不会直接报废），但可靠性大幅下降

- **何必呢？**  
  完全可以错开一点（哪怕0.2–0.3mm），没必要冒这个风险

## 5. 金属化过孔打在焊盘边上、与焊盘部分重叠会怎样？

**常见后果（严重程度递减）：**

- **焊锡容易流失**（最常见问题）  
  过孔吸锡 → 焊盘上焊锡减少 → 冷焊、虚焊、立碑风险大增

- **影响PCB局部机械强度**  
  焊盘边缘被过孔切掉一部分铜 → 焊盘附着力下降，长期振动/热胀冷缩易脱落

- **正规设计规范不允许**  
  IPC-2221 / IPC-7351 等标准中，过孔与焊盘边缘至少要保持一定间距（通常 ≥ 0.15–0.2mm，视工艺而定）

**结论：不推荐，尽量避免。**  
必须打时 → 考虑**盖油阻焊**或**塞孔**（plugged via）工艺。

## 6. 多层焊盘（铜皮）与PCB板框（外框/边框）部分重叠会怎样？

**最常见后果汇总：**

- **板边容易分层/爆板**（最严重）  
  多层铜皮延伸到板框区域 → V-CUT/铣边时铜皮被切断 → 层间应力释放 → 分层、爆板

- **电性能风险**  
  板框一般不走信号，但如果铜皮连到板框 → 可能引入额外寄生电容、EMI问题

- **表面处理异常**  
  板框区域通常不做沉金/OSP，铜皮暴露在外 → 容易氧化、影响美观

- **V-CUT后短路风险**（部分厂）  
  极少数情况下，切边不干净导致铜屑桥接

**规范做法：**
- 所有铜皮（包括地铜、电源铜）距离板框边缘至少 **0.5mm**（建议1mm以上）
- 板框区域只保留**阻焊层**和**丝印**，**严禁任何裸铜**
